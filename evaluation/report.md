基于当前 MySQL 中的五份 `ACTIVE` 说明书和 Qdrant 索引运行。评测集见 [golden.json](golden.json)：5 份文档的结构抽查、21 道单药检索题、1 道跨药比较题、7 道问答题（其中 2 道应拒答）。检索分别统计 BM25、向量、RRF 融合和精排后的排序结果。完整机器报告保存在本地 [latest.json](../data/evaluation/latest.json)。

## 根据失败样例完成的调整

- 识别省略剂型的药品名；把问题中明确提到和由意图推断出的章节合并。儿童剂量等问题不再因为缺失人群标签而在召回阶段被硬过滤。
- 允许回答中的“3级”由原文“3或4级”支持，仍拒绝原文未列出的等级和错误单位。
- 模型引用仅有 PDF 空白或换行差异时，恢复为原文中的连续片段；其他字词差异仍判为无效引用。
- 对引用校验失败的回答尝试一次带反馈的重试；模型明确说“未提供”或“未提及”时，统一给出证据不足的回答并移除不相关引用。
- 本地模型单次调用默认超时 120 秒，可用 `OLLAMA_CHAT_TIMEOUT_SECONDS` 调整，避免异常生成持续占用网页请求。

## 链路验证

- `python -m unittest discover -s tests -q`：86 个测试通过，5 个按配置跳过。
- `RUN_LIVE_E2E=1` 的真实链路测试通过：MySQL → Qdrant / BM25 → 精排 → qwen3.5 → 原文表格行引用。
- FastAPI 真实 HTTP 检查通过：首页、健康状态、原文详情和带药品筛选的问答 POST 均返回预期结果；问答返回达可替尼腹泻调整的表格行引用。
- 追加回归：“坎地沙坦酯片的不良反应有哪些”在真实问答链路和网页 POST 中返回带引用的回答；模型若给概览附加无依据的发生率，则退回逐字原文摘录。父块引用的原文详情也已通过 HTTP 检查。此题尚未纳入上表的黄金集指标。

## 当前边界

规格第 17.4 节提出的每药问题数量高于当前评测集；目前是可复现的起始集，不能把满分外推到所有药品问题。新增黄金题必须由人工核对原 PDF、药品版本和 chunk ID。厄贝沙坦“通常初始剂量”样例虽然引用正确，模型仍补充了特殊人群剂量；后续人工相关性审核应关注类似冗余内容。
